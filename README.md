# Launch Metrics & Go-Live Dashboard

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes launch performance and operational readiness using business, quality, compliance, recovery, and unit-economics metrics.

The objective is to provide a clear view of launch health and identify potential risks that may require corrective action or rollback.

## Business Objective

* Monitor launch performance and request success rates
* Measure failure rate and service reliability
* Track data quality and compliance
* Analyze recovery performance
* Evaluate revenue, cost, and profitability
* Identify high-risk regions and platforms
* Monitor rollback-trigger indicators

## Data Preparation

The raw dataset was cleaned in *Excel* by removing duplicate records, handling missing values, standardizing fields, validating numerical values, and formatting dates and metrics.

The cleaned dataset was then used for analysis and visualization.

## Tools & Technologies

* Excel — Data Cleaning
* Python — Data Analysis
* Pandas & NumPy — Data Processing
* Tableau — Dashboard & Visualization
* GitHub — Project Documentation

## Key Analysis Areas

The analysis covers:

* Overall KPIs
* Monthly Performance
* Region Performance
* Platform Performance
* Version Performance
* Launch Status
* Compliance
* Rollback Analysis
* Data Quality
* Unit Economics
* Reliability
* Business Insights

## Tableau Dashboard

The Tableau dashboard provides an interactive view of:

* Total Requests
* Successful Requests
* Failure Rate
* Approval Rate
* Revenue & Profit
* Quality Score
* Latency
* Recovery Time
* Compliance Rate
* Rollback Indicators

Filters can be used to analyze performance by date, region, platform, and version.

## Business Outcome

The project helps decision-makers monitor launch health, detect operational risks, understand financial performance, and take timely actions based on measurable indicators.

## Conclusion

This project demonstrates an end-to-end data analytics workflow from *Excel data cleaning to Python analysis and Tableau dashboard development*, with a focus on actionable business insights and launch monitoring.
